# TeaCat v1.0 naming

The project is now consistently named **TeaCat**.

- Product: TeaCat
- Maven groupId: `com.teacat`
- Maven artifactId: `teacat`
- Java package: `com.teacat`
- Main class: `TeaCatApplication`
- MySQL database: `teacat`
- Cloudinary folder: `teacat/pets`
- Local owner/test login remains `a` / `a` and is auto-created on first startup when absent.
